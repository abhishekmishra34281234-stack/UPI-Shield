# 🛡️ UPI-Shield: Fraud & Scam Detection Engine

A rule-based heuristic security scanner designed to detect phishing, UPI fraud, and panic-inducing spam messages.

## 🚀 Features
- **Threat & Urgency Detection:** Flags intimidating language (police, block, legal notice).
- **Phishing URL Detection:** Detects malicious links and shorteners (bit.ly, tinyurl).
- **Heuristic Scoring Engine:** Calculates real-time risk scores (Safe, Moderate, High Risk).
- **Web Interface:** Built using Flask and responsive CSS.

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, Jinja2
